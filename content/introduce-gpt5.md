## Safety & Training Innovations
### Enhanced Safety Measures
*   Mitigating hallucinations and deception
*   Significantly less deceptive than O3 and O4
### Overhauled Safety Training Approach
*   Old models: Outright refused or fully complied, leading to clever prompts sneaking through or legitimate questions being refused
*   **Safe Completion (New Approach)**
    *   Maximizes helpfulness within safety constraints
    *   Partially answers questions or answers at a high level
    *   Provides refusal explanations and helpful alternatives
    *   Better handling of tricky dual-use scenarios (e.g., technical details for fireworks material)
    *   Fewer "I'm sorry I cannot assist with that" responses
    *   Creates a more robust safety system
### New Training Techniques
*   Models leverage previous generation models to help create data
*   OpenAI crafts high-quality synthetic curriculum to teach complex topics
*   Breakthrough: Create the "right kind of data" shaped to teach
*   Foreshadows a recursive improvement loop where previous generations improve data for the next
*   First steps towards future AI systems beyond current pretraining and post-training pipelines

## API & Pricing
### State-of-the-Art Models
*   GPT-5, GPT-5 Mini, and GPT-5 Nano available in the API starting today
*   Optimized for cost and latency curve
*   GPT-5 Mini outperforms O3 on many dimensions
*   GPT-5 Nano is 25 times more affordable than GPT-5
*   GPT-5 priced at $1.25 per 1 million input tokens
### New Parameter Option
*   **Reasoning Effort "Minimal"**: Allows using reasoning models for very fast, latency-sensitive applications; dial in reasoning effort instead of choosing models
### New API Features
*   **Custom Tools**: Free-form plaintext for tool calls, addressing issues with long JSON arguments
*   **Structured Outputs Extension**: Supply regular expressions or context-free grammar to constrain model output (e.g., custom DSLs, SQL)
*   **Tool Call Preambles**: Model outputs explanations before calling tools; highly durable and follows instructions effectively
*   **Verbosity Parameter**: Control output terseness or expansiveness (low, medium, high)
### API Benchmarks
*   **Coding Model**
    *   SWEBench: 74.9% (up from 69.1% for O3)
    *   Aider Polyglot (all programming languages): 88% (stark improvement over O3)
    *   Front-end Web Development: Human trainers preferred GPT-5 70% of the time (improved aesthetics, better capabilities)
*   **Agentic Tool Calling**
    *   Leading state-of-the-art model
    *   Tower Square benchmark: 97% (up from max 49% two months ago)
*   **General-Purpose Instruction Following**
    *   COLLIE: 99%
    *   SCALES (multiturn instruction following): 70% (up 10 points from O3)
    *   In-house (real API use cases, hard subset): 64% (up from 40% for O3)
*   **Longer Context Window**
    *   400K total context (up from 200K for O3)
    *   State-of-the-art on OpenAI MRCR (128K and 258K) and Graphwalks BFS (reasoning over long context inputs)
    *   New "Rows Comp Long Context" eval open-sourced to spur work
